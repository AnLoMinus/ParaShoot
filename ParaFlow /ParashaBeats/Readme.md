# 🧬 **🔷 האלגוריתם (הגרסה הרשמית של AnLoMinus)**

כל שיר נבנה לפי אותו DNA קבוע:
הוא מייצר סדר, עומק ודיוק — לכל פרשה כל השנה.

## 🌀 1. **פתיח – “נשמת הפרשה”**

* משפט מרכזי מהפרשה (פסוק/רעיון/דמות).
* שאלת מפתח: *“מה ה’ מגלה לי בפרשה הזו?”*
* פתיח מוזיקלי: ליטוף חליל, תוף לב, קטורת־סאונד 🥁🌬️

---

## 📘 2. **הבנה – תקציר הפרשה ב־12 שורות**

⚡ תמיד קצר, קצבי וברור.
⚡ הפשט של האירועים בלי עומס.
⚡ מהלך עלילתי → מראשית עד סופה.

---

## 🔍 3. **הבהרה – מה באמת קורה כאן?**

כאן נכנס ה"מוח הפנימי":

* עומק קבלי
* עומק חסידי
* עומק מוסרי
* משמעות נסתרת

שאלה מנחה:
**מה התנועה הרוחנית שהפרשה יוצרת בי?**

---

## 💎 4. **ליקוט פנינים – דרשות קצרות ומדויקות**

כל פנינה =

* 🔹 רעיון
* 🔹 פסוק
* 🔹 רמז
* 🔹 מסר תודעתי

3–7 פנינים לכל פרשה.
קצרות, חדות, נוגעות.

---

## 📜 5. **הלכה למעשה – “המסלול המעשי לשבוע”**

הופך את הפרשה ליישום ממשי:

| תחום         | מעשה השבוע      |
| ------------ | --------------- |
| 🌿 מידות     | פעולה לשיפור    |
| 🛡 התגברות   | התמודדות עם יצר |
| 🕯 קדושה     | קבלה שבועית     |
| 🤝 אדם לחברו | מעשה חסד        |
| 🧠 תודעה     | נקודה פנימית    |

---

## 🔧 6. **תיקון – “מה לתקן השבוע?”**

כולל:

* חטא/בלבול/חולשה של הדור או של הדמות בפרשה
* איך זה מופיע בי
* איך לתקן את זה בשיעור אחד מעשי
  נוסחה:
  **דמות → טעות → שורש → השלכה בנפש → תיקון → תוצאה**

---

## 🕊 7. **השלמה – “אור סוף הפרשה”**

שורת אור שמסכמת את כל השבוע.
כמו “פזמון פנימי”:
משפט קצר, מחזק, מעורר.

לדוגמה:

> “מי שצועד עם האמת – האור מפנה לו דרך.”

---
